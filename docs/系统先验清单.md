# RF-CEM Semantic Acquisition 系统先验清单

**版本**：v0.1　**日期**：2026-08-29
**用途**：盘点自动学习模块（SA 路线）中全部先验知识，说明其形态、作用位置、失效模式与出口。
**总原则**：系统不追求无先验，而追求**先验全部显式化、版本化、可测量、有失效出口**。任何隐性先验（代码里硬编码但未声明的假设）一经发现按缺陷处理。

---

## 0. 阅读方式

每个先验按五列描述：**形态与位置**（它存在哪）、**如何影响系统**（它决定什么）、**失效模式**（它错的时候发生什么）、**失效出口**（系统如何不死）、**可测量性**（怎么知道它出了问题）。

先验按"失效后果从重到轻"排序：结构性先验（错了系统产出错误答案）在前，精化性先验（错了只是精度降级）在后。

---

## 1. 结构性先验（决定搜索空间与合法性）

### 1.1 Canonical Domain 先验：轴对称单 cell RF 真空轮廓

- **形态**：范围声明。v0 只覆盖轴对称、单 cell、RF 真空壁，归一化弧长域 u=s/L ∈ [0,1]；
- **影响**：整个表示体系的地基。轮廓提取、atom 网格、曲率信号、region 拓扑全部建立在其上；
- **失效**：遇到非轴对称结构（FPC、tuner、coupler 端口）、多 cell 腔、非真空壁 → 表示直接不适用；
- **出口**：显式范围声明 + NC/SRF 隔离不变量 + 输入分类 fail-closed（不满足 `axisymmetric_single_cell_rf_vacuum` 的输入被拒绝，而非被强行处理）。多 cell/非轴对称是 roadmap 明示的未来扩展，不是缺陷；
- **可测量**：输入分类审计；不适用输入必须出现在拒绝日志而非结果里。

### 1.2 Ontology 先验：6 种 region type + 3 种 landmark type

- **形态**：`semantic_region_ontology.v0` / `semantic_landmark_ontology.v0`，人审冻结的封闭标签集；
- **影响**：LLM 的选择空间。标注只能从封闭集 + `unknown` + `abstain` 中选；ontology 定义的措辞直接塑造模型判断；
- **失效**：真实存在的新语义（新 region 类型）被强迫归入最近的已知类型——**这是全系统最危险的失效**，因为它静默产生貌似合法的错误答案；
- **出口**：`unknown`/`abstain` 出口 + "证据不足不强迫分类"原则 + 异常队列 + SA8 的跨实例 unknown 聚类与 ontology 扩展流程（新语义需要跨实例支持或强证据，patch 不自动应用）；
- **可测量**：unknown/abstain 率按区域分布监控；同一形状模式的 unknown 在多个实例重复出现 = ontology 缺口信号。

### 1.3 Family Grammar 先验：backbone 序列、基数、motif 规则

- **形态**：`family_grammar.v0`（端点必须 BeamPipe、中心必须 Equator、nose 必须成对、邻接/基数约束），R1 验证器内建；
- **影响**：组装图的硬合法性约束；也是确定性异常检测器——标签序列与期望 backbone 的偏差 = 异常信号，由控制面检测而非模型报告；
- **失效**：合法的新拓扑被 grammar 拒收（假阴性）；
- **出口**：R3 的提案-审核-patch 机制（TD3 已实现 intrinsic-valid 与 family-admission 分离：图可以内在合法但未获家族准入）；grammar 突变必须经人审 patch，永不自动；
- **可测量**：被拒图的分类统计（内在非法 vs 内在合法但未准入）；后者累积 = grammar 扩展信号。

### 1.4 评测先验：容差与匹配定义

- **形态**：覆盖容差 Δu≤0.02、拓扑匹配定义、per-type precision/recall 口径；
- **影响**：它不决定系统产出什么，但决定我们**相信系统什么**——所有出门判据、benchmark、自动准入门槛都以其为尺；
- **失效**：容差过松 → 虚高质量估计；过紧 → 误杀可用结果；
- **出口**：事先冻结、写进规格文件、修改需双方确认并留历史（本清单与 slice 规格的治理规则）；
- **可测量**：容差取值须有实测依据（如 A0 命中精度 ~1 mm 支持 0.02 的覆盖容差不是过松）。

## 2. 引导性先验（塑造 LLM 判断，但有验证兜底）

### 2.1 原型检索先验：已审实例库（"学习"的真正载体）

- **形态**：人审实例的积累库 + 检索机制（形状摘要相似、位置相似）；
- **影响**：LLM 标注的核心依据是类比先例。先例库的质量和覆盖直接决定标注质量——**系统的学习 = 先例库的增长，不是参数更新**；
- **失效**：先例库偏置（目前只有椭圆圆腹 NC 单 cell）→ 新 family 的首批实例没有可类比先例，标注质量低；
- **出口**：新 family 首批实例预期走人工标注（异常队列是常态入口而非例外）；先例库覆盖度是显式指标；检索不到相似先例时模型被明确告知而非静默；
- **可测量**：先例库 family 覆盖分布；每实例的检索命中质量记录。

### 2.2 Prompt/Provider 先验：模型选择、prompt 措辞、温度

- **形态**：版本化 prompt 模板 + provider 配置；
- **影响**：标注质量与稳定性的直接来源之一；同一语义换个措辞可能得到不同标签；
- **失效**：prompt 敏感性、provider 版本漂移导致结果不可复现；
- **出口**：温度 0 + 重复运行 3 次测稳定性 + 不一致即 abstain + yellow path（第二 prompt/强模型 critic/替代 provider）+ v0 全人工准入；
- **可测量**：重复运行不一致率按 atom 分布；prompt 版本间 A/B 比较。

### 2.3 文献证据先验：证据分级与来源信任

- **形态**：`literature_semantics.v0` 的证据层级（literal / deterministic_derived / model_perceived / cross_modal_inferred）、单篇数值默认 soft-only、NC/SRF 隔离；
- **影响**：证据锚点是光滑语义边界**唯一**的精确位置来源（A0 已证几何信号对此类边界不可见）；证据分级决定其可用强度；
- **失效**：图的版面惯例因实验室/年代而异；提取错误；模型幻觉引用；
- **出口**：引用必须指向真实存在的证据 ID（幻觉 fail-closed）；图像-only 证据不支持硬数值规则（既有安全模型）；人审保留；
- **可测量**：证据引用正确率单独测量（SA5 指标中已列）。

## 3. 精化性先验（只影响精度，不影响可达性）

### 3.1 几何信号先验：5 条确定性规则及其阈值

- **形态**：A0 的信号集 v0（端点、半径极值、曲率零点/极值、连续性突变、对称点）+ 事先声明的阈值族；
- **影响**：**仅**精化相的吸附目标与标注的弱先验。A0 的核心教训：此类先验若决定搜索空间则致命（4/8 覆盖），降级为精化目标后失效只是精度降级；
- **失效**：信号缺失（光滑语义边界）→ 边界停留在区间宽度；信号误触发 → 错误吸附；
- **出口**：稠密网格兜底保证可达性；`basis` 出处字段使每次吸附可审计；shadow 模式下错误吸附可测量、可降级具体信号；
- **可测量**：吸附误差分布按信号类型分列；
- **扩展纪律**：新增信号必须是**通用几何事件**，版本化；只针对特定 family 才触发的"语义化信号" = 把答案偷运进先验，审核拒收。

### 3.2 网格先验：均匀弧长 Δu=0.01（atom_grid.v0）

- **形态**：版本化网格规格，100 atom；
- **影响**：边界精度下限（未精化边界残差 ≈ 网格宽度）；LLM 标注对象数量；
- **失效**：真实 region 窄于网格宽度 → 标签转变无法表达（区域被吞并）；
- **出口**：窄区域告警（region 最小弧长约束）；网格规格版本化可加密（代价是标注对象变多）；
- **可测量**：A0.5 直接测量两实例 18 个 junction 的转变区间包含性与残差宽度。

### 3.3 约定先验：family 级边界约定规则

- **形态**：（规划）语义模板中的版本化约定，如"equator 区域约定为赤道冠切向角 ±X°"；
- **影响**：文献沉默、几何光滑的"约定俗成"边界的兜底出处；
- **失效**：约定对某 family 不适用；
- **出口**：约定按 family 分作用域、人审、版本化；`basis=family_convention` 使这类边界在准入策略中可被区别对待；
- **可测量**：约定与文献锚点冲突的发生率（冲突进异常队列）。

### 3.4 组装规则先验：合并、吸附、窄区域吸收规则

- **形态**：事先冻结的确定性规则（中点规则、最近吸附、并列取小 u 等）；
- **影响**：标签序列如何变成图——规则选择影响边界归属；
- **失效**：规则 bug 或对特定拓扑不适用；
- **出口**：A0.5 oracle 仿真正是为此设计——完美标签下组装必须复现已审图，否则规则有 bug；单元测试覆盖；
- **可测量**：oracle 仿真中组装图与已审图的序列一致性。

---

## 4. 治理性先验（决定什么能进入 canonical）

### 4.1 准入策略先验：green/yellow/red 门槛

- **形态**：（SA6 规划）按语义类型开放的自动准入政策；
- **影响**：什么结果能写入 canonical 知识库；
- **失效**：假自动准入（错误结果被信任并污染先例库——先例库是学习载体，污染会自我放大）；
- **出口**：v0 全人工准入；自动权限按 semantic 类型逐类开放且须 benchmark 达标；随机抽查；rollback/supersede 可追溯；
- **可测量**：false automatic-admission rate 单独测量（SA5 已列）。

## 6. 三条元规则

1. **先验只能显式存在**：任何影响系统行为的假设必须出现在本清单中；发现隐性先验 = 缺陷；
2. **先验的强弱要有实测依据**：A0 把几何信号从结构性降级为精化性，就是实测驱动的先验降级——这是本系统演进的标准动作；
3. **失效出口先于先验生效**：任何先验在引入时必须同时声明其失效出口，无出口的先验不入库。
