# Semantic Acquisition Slice 规格（A0–A3）与审计参考

**版本**：v0.1（审计员留存，暂不发执行方）
**日期**：2026-08-29
**用途**：A0–A3 探针链的统一规格 + 每阶段结果审核清单。执行方只收到当阶段的任务 prompt；本文件是审核时的对照基准，防止范围蔓延和出门判据被事后放宽。

---

## 0. 总原则（每阶段审核时先核对）

1. **每个设计元素必须回答"它防的是哪个已测得的失败模式"**，答不上来的推迟；
2. 真值与待测机制必须**来源独立**（防循环验证）；
3. 概率性输出（LLM）永远不直接产生 hash、review binding、canonical 写入——这些只属于控制面；
4. 每阶段硬出门判据在本文件中**事先冻结**，审核时逐条对照，不接受事后修改判据；
5. 失败是合法结果：任何阶段未达标，记录诊断、停下、回到本文件修订，而不是加码建更复杂的机制绕过。

## 1. 循环论证风险地图（审核时保持清醒）

| 资产 | 归纳来源 | 用作测试时的风险 |
| --- | --- | --- |
| R1 ontology / family_grammar.v0 | SLS-2 + RF500 已审图 | 对这两个实例做标注测试 ≈ 泄题，高分只证明管线能跑通 |
| SLS-2 / RF500 已审图 | 人工审核 | 几何真值本身干净，A0 可用；A1–A3 仅作回归/调试 |
| LEReC 盲审图 | R3 盲测，未参与 grammar 训练 | **A1–A3 唯一干净的主测试对象** |
| `literature_semantics.v0`（SLS-2） | 该论文证据，人工已审 | 作为 A2 的文本证据输入合法，但它只覆盖 SLS-2 |

结论：A0 的几何信号覆盖率测试对 SLS-2 无循环风险（测的是信号，不是语义）；A1 起语义测试的主证据只能来自 LEReC，SLS-2/RF500 结果只能标注为"管线回归"。

## 2. A0：确定性 landmark 覆盖率（纯控制面，零 LLM）

**假设**：真实 region junction 几乎全部落在确定性几何信号可提出的候选切点上。
**若证伪**：roadmap §4.2/4.3 的有限 atom 搜索空间不成立，SA 路线需要重新设计边界分区机制（这是最有价值的早期失败）。
**若证实**：LLM 任务从开放生成退化为有限集分类，后续阶段复杂度大幅下降。

**出门判据**（已在任务 prompt 中冻结）：
1. 真值 junction 100% 命中（Δu ≤ 0.02）或逐个未命中诊断；
2. 候选统计完整量化；
3. 确定性重建字节一致；
4. 全量 no-CST 测试通过；
5. 零修改现有文件；
6. 备份记录完整。

**A0 结果审核清单**（拿到 handoff 后逐项核对）：
- [ ] 分支基线正确：`codex/rf-cem-acquisition-a0-landmark-coverage` 从 canonical HEAD 切出，PR #10 状态被正确处理；
- [ ] LEReC 搜索是真实的：报告列出了实际搜索路径，而非直接回退 SLS-2；
- [ ] **真值独立性**：junction 真值来自 compile_record.v2 的 landmark 绑定 / R1 已审图，而非本任务信号代码的输出；抽查 2–3 个 junction ID 到源文件核实；
- [ ] 阈值未事后调优：Δu = 0.02、最小间距 0.005、多尺度密度为事先声明值；若报告中出现其他值，要求说明声明时间；
- [ ] 连续性突变检测的数值阈值与编译记录连续性诊断做了交叉印证，而非孤立自定；
- [ ] 复跑确定性：自己重跑一次 CLI，比对输出哈希；
- [ ] `git diff --stat` 只有新增文件；`observation/` 等私有函数确实未被 import（grep 验证）；
- [ ] 可视化图人工过目：候选点分布是否合理（比如是否在赤道冠、iris 根部这些预期位置密集）；
- [ ] 额外候选率记录下来——它是 A1 分类任务难度的先验估计。

## 2.5 A0.5：稠密 atom 表示的 oracle 标签仿真（A0 结论触发的插入阶段）

**背景**：A0 实测证伪"几何信号提候选完备"（SLS-2 命中 4/8，未命中者为光滑语义边界，几何上不可恢复）。表示方案改为混合式：稠密均匀网格为搜索空间基底，信号候选降级为精化相吸附目标。网格密度经用户拍板为 **Δu=0.01（100 atom，atom_grid.v0）**。

**假设**：oracle（完美）标签下，"网格 + 转变检测 + 吸附精化 + 图组装"链路能完备复现已审图。
**若证伪**：组装/精化规则有 bug 或网格粒度不足，在花费任何 LLM 成本前暴露。
**关键产出**：未吸附边界的残差区间宽度分布 = 无文献锚点时的边界精度下限，是 A2 必要性的量化依据。

**冻结规则**（写入任务 prompt，审核时对照）：
- oracle 标签 = atom 中点所在已审 region 的类型（中点规则，无替代方案）；
- 转变区间 = [左 atom 中点, 右 atom 中点]，宽度 Δu；
- 精化：区间内 ≥1 个稳定信号候选 → 吸附距区间中点最近者（并列取小 u），`basis=geometric_signal`；无候选 → 保留区间，`basis=unrefined_interval`；`literature_anchor`/`family_convention` 仅预留枚举不实现；
- 实例：SLS-2（8 junction）+ RF500（10 junction，编译 ID `b46af83bb85674d5`）。

**出门判据**：18/18 junction 被转变区间包含；oracle 组装图过 R1 验证器 + grammar 验收且序列精确一致；吸附误差/残差宽度/basis 分布量化；字节级确定性；变更仅限 `semantic_acquisition/` 与测试。

**A0.5 审核清单**：
- [ ] 在 A0 分支上继续提交（Draft PR 覆盖 A0+A0.5），无新分支；
- [ ] 中点规则、转变区间定义、吸附优先级与 prompt 冻结文本逐字一致；
- [ ] oracle 标签未写入任何 proof/canonical（grep `simulated_oracle` 标记）；
- [ ] 残差区间宽度分布 ≈ 0.01 量级；若显著更宽，查网格实现而非接受结论；
- [ ] RF500 的 nose 边界吸附精度单独看（nose tip 是半径极值，预期 ~1 mm）；
- [ ] `basis` 枚举含两个 reserved 值且未实现；
- [ ] 复跑确定性；diff 范围核对。

## 3. A1：闭卷 atom 标注（LLM 下限测试）

**前置**：A0 通过（或带明确诊断通过）。
**问题**：LLM 仅凭 atom 形状摘要 + ontology 定义，无文本无图，能标对多少？
**主测试对象**：LEReC（唯一干净）。SLS-2/RF500 只作管线回归，结果不具泛化证据效力。

**输入构造（控制面）**：
- A0.5 的 atom_grid.v0 稠密 atom（100 个），每个 atom 附形状摘要：u 区间、半径范围、曲率符号/均值、单调性、凸性（A0 的信号候选仅作为弱先验附注，不再决定搜索空间）；
- ontology 子集：6 种 region type 的操作性定义（不含任何实例名、不举例 SLS-2/RF500——防泄题）；
- 严格 JSON 输出 schema：逐 atom `{label | abstain, rationale, evidence_atom_ids}`；不允许发明新类型。

**控制面职责**：prompt 编译、schema 校验、引用回查（rationale 引用的 atom id 必须存在，否则 fail closed）、原始响应与 token/成本落盘。

**出门判据**：
1. LEReC 上逐 atom 标注的 per-type precision/recall 可计算（对照盲审图）；
2. 模型违反 schema 或引用不存在 atom 时确实 fail closed（构造反例测试）；
3. abstain 路径可用且被量化；
4. 同一输入三次运行的标注稳定性有记录（温度、随机性声明）；
5. 原始响应、prompt 版本、成本全部留痕。

**审核要点**：ontology 定义文本人工检查无泄题；fail-closed 反例测试真实存在；不要接受"模型看起来标得挺对"这种定性结论，只要混淆矩阵。

## 4. A2：开卷标注（证据增量测试）

**前置**：A1 完成（无论好坏——A1 差正是 A2 要补的信息）。
**问题**：加入文献文本 + 图像证据后，标注质量提升多少？模型能否正确引用证据？

**增量输入**：
- LEReC：两篇 hash 绑定 PDF 的文字提取 + 页面渲染图（`pdf_evidence.py` 已有渲染能力）；
- SLS-2（回归用）：冻结的 `literature_semantics.v0` 直接作为文本证据；
- 输出 schema 增加 `evidence_refs`：必须指向输入证据包中真实存在的证据 ID，幻觉引用 fail closed。

**出门判据**：
1. 相对 A1 的 per-type 增量可计算（Δprecision/Δrecall/Δabstain）；
2. 幻觉证据引用 fail closed 有反例测试；
3. 文本-only 与 文本+图像 两个变体分别报告（判断视觉通道的必要性）。

**审核要点**：证据包内容人工抽查（确认喂给模型的不含答案本身，例如 LEReC 盲审图的任何派生物）；图像证据的页面选择过程留痕。

## 5. A3：全图组装 + R1 契约验收

**前置**：A2 完成。
**问题**：标注结果经控制面组装后，能否通过现有 R1 验证器/grammar 验收，并与已审图在容差内一致？

**流程**：
1. 控制面合并相邻同标签 atom → region 序列（含合并策略：短区域吸收规则事先声明）；
2. 薄 adapter 把 draft 补全为完整 `instance_boundary_graph.v0`：`review`/`source_feature_ids`/hash 由控制面合成（LLM 永不产这些字段）；
3. 跑现有 R1 验证器 + grammar 验收（fail-closed 已内建）；
4. 与已审图比对：有序 region type 序列精确匹配、junction 位置 Δu 容差、motif 激活一致性。

**出门判据**：
1. LEReC 有序类型序列与盲审图一致（正确得出 `known_optional_motif_present` 结论）；
2. 结构性先验（端点 beam pipe、中心 equator、nose 成对）由 validator 强制而非 prompt 告知——审核时检查 prompt 文本确认未泄露；
3. 错误案例（故意构造的非法图）被 validator 拒收有测试；
4. junction 位置偏差全部量化。

**审核要点**：这是"解耦是否成立"的最终证据——prompt 里不得出现结构规则，规则全部在 validator；若为了让图通过验收而往 prompt 里加结构提示，视为解耦失败信号，记录并讨论。

## 6. 阶段间控制

- A0 → A1 前：开一次短评审，确认 atom 空间完备性结论；
- A1 → A2 前：确认 A1 的混淆矩阵，决定证据通道优先级；
- A2 → A3 前：确认证据引用可靠性；
- A3 通过后：才回到 roadmap 决定 SA1（契约冻结）需要冻结什么——届时有实测数据支撑，契约从使用中生长而非凭空设计；
- 任何阶段发现需要修改本文件判据：先记录原因，双方确认后再改，保留修改历史。

## 7. 明确不做清单（A0–A3 全程有效）

- 不建 Workbench 页面（可视化用静态 PNG/HTML 报告）；
- 不建 corpus 调度、缓存、批量 API（SA7 内容）；
- 不做自动准入（admission 全程人工）；
- 不做 open-world 新语义发现（SA8 内容）；遇到未知 → abstain，不强迫分类；
- 不做 taxonomy 全景调研（SA0/DR-01 降级为后台参考）；
- 不触碰 NC/SRF 隔离：探针全程只用常导案例；
- 不修改 R0B–R5 任何既有契约、证明、文档。
